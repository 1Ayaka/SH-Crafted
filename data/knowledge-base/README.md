# SH-Crafted 可追溯知识库

此目录把比赛视频证据与外部权威资料统一为可检索知识库。外部网页抓取结果不能直接作为事实；只有 `facts.jsonl` 中带来源引用、来源等级和审核状态的条目才进入网页问答。

## 文件

- `sources.json`：来源登记册、权威等级、主题和抓取策略。
- `facts.jsonl`：人工整理或待复核的外部事实，每条必须引用来源。
- `snapshots/`：抓取脚本生成的网页文本快照，仅用于核对和后续整理，不直接发布。
- `index.jsonl`：构建脚本生成的统一检索索引，包含视频证据、视频主张、工序、外部事实、实体和来源。
- `stats.json`：覆盖率和质量统计。

## 来源分级

- A：国家级政府部门、国家级非遗名录、上海市政府正式名录。
- B：上海市/区级政府、文化主管部门、公共文化机构。
- C：政府指导的官方文旅平台、国有文化机构或权威媒体转载。
- 百科、自媒体、电商和无署名转载不进入可靠来源集合。

## 命令

```bash
npm run kb:build
npm run kb:crawl
npm run kb:links
npm run kb:audit
```

`kb:build` 会进行引用完整性、重复编号、项目覆盖和空文本检查；任何硬错误都会以非零状态退出。`kb:crawl` 默认只抓取登记为 HTML 且启用的页面，并先检查 `robots.txt`。`kb:links` 会检查全部 HTML/PDF 原文链接的当前可访问性。`kb:audit` 会复核抓取结果、快照哈希、索引规模以及每个项目的事实和来源覆盖率。

当前硬性覆盖门槛为：每个上线项目至少 10 条外部事实、5 个独立来源、6 类事实主题，并至少具有 A/B 级来源支持。

## 审核原则

1. 视频转写继续标记为 `needs_review`，并保留时间码。
2. 外部事实采用摘要性表述，不复制整篇网页。
3. 涉及名录级别、人物、年代、工序和保护单位时，优先采用 A/B 级来源交叉核对。
4. 来源冲突不覆盖，建立独立冲突记录并转人工审核。
