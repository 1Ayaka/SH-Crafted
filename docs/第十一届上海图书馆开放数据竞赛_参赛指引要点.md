# 第十一届上海图书馆开放数据竞赛：参赛指引要点

> 本文根据《01 第十一届上海图书馆开放数据竞赛参赛指引.pdf》整理，重点提取与“上海非遗交互系统”相关的内容。具体提交页面和最终规则以主办方最新通知为准。

## 一、赛事定位

上海图书馆开放数据竞赛不只是作品比赛，也是数字人文、文化创意与人工智能的交流和实践平台。

竞赛鼓励参赛者：

- 使用真实文化数据开展创作与研究。
- 挖掘文化数据的深层价值和新内涵。
- 使用人工智能等新兴技术进行创新应用。
- 将创意转化为可以实际体验或使用的应用。

2026 年主题为：

> **典籍新生，数据里的文脉风华**

该主题是创作方向上的精神召唤，不是限定题目。作品应关注数据本身，并进行内涵化创新。

## 二、与你的项目最匹配的赛道和方向

### 推荐赛道：应用开发及智能体赛道

你的项目包含交互网页、数据展示、3D 体验空间和智能体，最适合申报“应用开发及智能体赛道”。

### 推荐方向：方向三——焕发非遗新生，演绎江南风韵、海派之美

官方方向鼓励：

- 基于民俗影像、地方曲艺、老电影、艺术图像和地域知识，开发面向公众的创新演绎和多感官体验应用。
- 通过多模态生成、沉浸式交互等技术活化文化遗产。
- 开发非遗技艺的互动式解谜与创作体验。
- 通过交互方式展示上海地域文化和非遗传承。

官方特别提示：该方向资源特色突出，但历年作品偏少，建议重点关注。

### 可借鉴的其他创作方向

虽然非遗方向最适合你的项目，但以下方向也可以作为扩展思路：

- **方向一：从沉睡典籍到可感可触的文化现场**
  - 可将非遗相关古籍、地方志、历史图像等作为文化背景数据。
  - 可使用 AI 进行图像解析、语义关联和知识生成。
- **方向二：在时空经纬中探寻人物与历史**
  - 可补充非遗传承人、历史地点、历史事件，形成“项目—人物—地区—时代”的关联叙事。
- **方向五：从公共行为洞见城市的文化脉动**
  - 后续可加入用户浏览、收藏、体验等行为数据，用于推荐非遗项目或分析公众兴趣。

## 三、项目应该重点证明什么

评审不会只看“页面是否好看”或“是否使用了 3D”，需要清楚证明以下几点：

### 1. 开放数据应用度

要说明官方数据具体用在了哪些模块，而不是只在介绍中提到数据。

建议在项目中明确展示：

- 哪些数据用于上海地图和行政区分布。
- 哪些数据用于非遗项目详情、类别、年代和传承信息。
- 哪些数据用于制作流程、人物关系或地域关联。
- 智能体回答依据了哪些数据字段和资料来源。
- 3D 模型中的内容如何对应真实非遗项目和真实工艺步骤。

### 2. 数据与其他资源的关联

比赛允许在官方数据基础上融合其他公开、合法且没有版权争议的辅助数据。

需要记录并说明：

- 数据来源和链接。
- 数据授权或使用范围。
- 数据清洗、整理和预处理方式。
- 不同数据之间如何关联。
- 哪些内容是原始数据，哪些内容是团队加工或生成的。

### 3. 创意与叙事

官方强调要从“展示”走向“讲述”。因此，项目不应只是“非遗项目数据库 + 地图”，而应形成一条有情绪、有地域关系的探索故事。

建议叙事主线：

```text
上海的地理空间
  → 一个地区的生活方式
  → 一项非遗工艺的形成
  → 一件作品的制作过程
  → 传承人与当代生活
```

### 4. 体验创新

官方希望用户从“旁观者”变成“参与者”。你的 3D 工艺体验是重要优势，但需要设计明确的用户行为，例如：

- 选择材料。
- 使用工具。
- 按正确顺序完成工艺步骤。
- 观察操作对作品形态的影响。
- 通过智能体获得解释和提示。

### 5. 技术创新与可用性

可以使用 3D、AI、多模态交互等技术，但技术应服务于文化理解，而不是单纯展示技术效果。

同时，技术测评会关注：

- 功能是否完整可用。
- 系统响应速度。
- 实际开发工作量。
- 数据使用情况。
- 安装、部署和试用是否顺畅。

## 四、评审流程与考察维度

应用开发及智能体赛道预计包括以下环节，具体以当年安排为准：

1. **形式审查**：检查是否符合提交要求。
2. **技术测评**：安装部署、试用体验和源码检查。
3. **书面专家评审**：结合提交材料、技术测评和应用展示进行评审。
4. **答辩专家评审**：现场介绍、演示和答辩。

重点考察维度：

- 作品创意。
- 设计与交互。
- 开放数据应用度。
- 外部数据关联度。
- 技术先进性。
- 实际工作量。
- 应用价值。

## 六、应用开发及智能体赛道提交材料

提交页面可能有微调，当前指引列出的内容包括：

- 作品名称。
- 作品形式，例如微站、小程序、Android App 等。
- 数据使用情况：说明使用了哪些数据，以及用在哪个阶段或模块。
- 应用选题方向。
- 作品摘要。
- 作品说明。
- 程序、微站访问地址或微信小程序二维码。
- 源代码压缩包，指引要求不超过 500MB。
- 作品介绍 PPT/PDF。
- 可选：作品 Logo 和补充材料。

补充规则：

- 一个队伍可以提交多个赛道作品。
- 每个赛道或子赛道只能提交 1 个作品。
- 团队成员可在提交作品时更新。

## 七、必须遵守的规则

- 作品必须基于本届上海图书馆开放数据竞赛发布的官方数据集创作。
- 可以融合其他公开、合法且无版权争议的辅助数据。
- 竞赛开放数据仅授权本届竞赛非商业使用。
- 必须遵循各数据提供方的授权协议。
- 不得篡改、伪造数据，也不得用于非法或未授权用途。
- 作品必须是未发表的原创作品，并具有创新性和独特性。
- 内容导向须正确，符合国家法律法规和社会主义核心价值观。
- 人气奖投票会被监控，禁止刷票。
- 获奖作品知识产权由作者、上海图书馆（上海科学技术情报研究所）、上海图情信息有限公司及相关数据支持方共有，参赛前应充分了解这一点。

## 八、针对你的非遗项目的落地建议

### 项目定位建议

将项目从“上海非遗展示网页”进一步表述为：

> 一个基于上海图书馆开放数据的非遗数字人文体验系统，通过地图叙事、3D 工艺交互和智能体讲解，让公众从地域、人物、工艺和作品四个层面理解上海非遗。

### 首版功能优先级

建议先做一个完整样板，再扩展项目数量：

1. 上海地图：展示行政区与非遗分布。
2. 一个地区页：展示该地区非遗分类和代表项目。
3. 一个非遗详情页：完成完整数据介绍。
4. 一个可操作的 3D 工艺流程：至少包含 3—5 个步骤。
5. 一个资料可追溯的智能体：支持问答、术语解释和步骤提示。
6. 作品介绍材料：清晰说明数据、技术、交互和文化价值。

### 作品中必须准备的“数据使用说明”

建议制作一张数据流向图：

```text
官方非遗/地方文化数据
  → 清洗与字段标准化
  → 地图分区与项目索引
  → 非遗详情内容
  → 工艺流程结构化
  → 3D 交互步骤
  → 智能体知识库与推荐
```

每个页面都应能回答：“这个页面的内容来自哪份数据？经过了什么处理？最终为用户解决了什么问题？”

## 九、最终检查清单

- [ ] 明确报名赛道为“应用开发及智能体赛道”。
- [ ] 选题对应“焕发非遗新生，演绎江南风韵、海派之美”。
- [ ] 使用至少一批官方竞赛数据，并在材料中具体说明用途。
- [ ] 为辅助数据保留来源、授权和处理记录。
- [ ] 项目不止展示信息，具有清晰的文化叙事。
- [ ] 用户可以在 3D 空间中完成实际操作或流程体验。
- [ ] 智能体回答基于可核验资料，并能提供来源或依据。
- [ ] 网页可访问、功能可用、加载速度可接受。
- [ ] 准备源代码、访问地址、作品说明和介绍 PPT/PDF。
- [ ] 作品尚未公开发表，并检查知识产权和素材版权。
- [ ] 按最终提交页面要求再次核对格式和大小限制。

## 十、对项目最重要的结论

你的方向与本届赛事的非遗创作方向高度契合，尤其符合官方提出的“非遗技艺互动式解谜与创作体验”。后续开发应围绕三个核心问题展开：

1. **数据是否真正成为系统内容和交互的基础？**
2. **用户是否从观看者变成了工艺体验的参与者？**
3. **3D 和智能体是否帮助用户理解非遗，而不只是增加视觉效果？**

只要围绕这三个问题打磨，项目在选题匹配度、开放数据应用度、叙事创新和体验创新方面都会更完整。

## 十一、现有方案审视后的优化结论

对照评审维度检查后，现有方案最需要解决的不是增加更多页面，而是让数据、交互、3D 与智能体形成可验证的关系：

- 地图上的区块状态、项目按钮和筛选必须由真实项目数量与类别驱动，地图不再用粒子遮挡模型；水墨粒子只用于详情页成品展示，并明确标注为视觉化效果。
- 地区页应解释地域、生活方式与非遗形成之间的关系，避免随机漂浮卡片。
- 首版采用“全市数据可见、一个地区深入、一个非遗完整可做”的范围，保证完成度和技术稳定性。
- 3D 流程以“材料—工具—动作—变化—工艺解释—资料依据”为统一结构，并注明是基于资料简化的体验性模拟。
- 智能体限定为资料问答、步骤指导和关联推荐；事实性回答必须附来源，无依据时不补全内容。
- 增设“数据与创作说明”页，公开数据字段、处理流程、外部资料、模型和 AI 使用范围。
- 为 WebGL、粒子动效和移动端准备降级方案，并支持键盘、列表视图和减少动态效果。

视觉方向确定为“海派水墨数字展陈”：以宣纸砂色留白、松墨绿和青绿矿物色为主，彩色只在数据类别和关键步骤中小面积出现；水墨负责空间结构和转场，粒子负责数据状态，3D 只承担核心工艺体验。标志性交互为“墨迹聚散”，即数据出现时聚成地图、项目和工艺部件，筛选或离场时沿湿墨边缘散开。

完整的优化方案、逐页交互与视觉规范见：[上海非遗交互系统——产品、交互与视觉方案](./上海非遗交互系统_产品大纲.md)。
