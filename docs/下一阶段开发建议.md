# SH-Crafted 下一阶段开发建议

本文基于《上海非遗交互系统——正式开发产品大纲》和《第十一届上海图书馆开放数据竞赛：参赛指引要点》，结合当前 v1 代码与素材状态整理。目标不是继续堆叠页面，而是把“数据—证据—交互—模型—部署”闭合成可验证的作品。

## 一、当前版本已经具备的基础

- 8 个非遗项目已经有统一的数据结构、详情页、工序工作台和知识库入口。
- 地图使用真实厚度的 `上海map_v2.glb`，行政区可以单独选择；地图页已移除边缘粒子，保持玉石模型和水墨背景的留白。
- 风筝与皮影戏完成品已接入成品模型路径。成品粒子使用 GLB 的 baseColor 贴图取色，并提高采样密度；粒子会以不同密度轻微下坠、渐隐，再从原位补回。
- 管理员可以编辑内容和工序，模型、证据与知识库仍应保持来源和审核状态。

## 二、上线前必须完成（P0）

### 1. 锁定一个“完整样板”

建议选一个资料、步骤、模型和证据最完整的项目作为答辩主线。风筝适合展示“结构—彩绘—放飞”，皮影适合展示“影人细节—透光—操纵”；二者不要同时承担全部叙事。其余项目先保证浏览、来源和空状态正确。

### 2. 做数据护照，而不是只放来源链接

每个项目至少记录：官方数据集字段、纪录片文件与时间码、外部资料 URL、授权范围、清洗/抽取方式、人工审核状态、最后更新时间。详情页和智能体回答都要能打开对应记录，评审才能看见开放数据如何变成页面内容。

### 3. 建立内容发布流程

管理员保存后先进入草稿，另一个协作者确认后再发布；发布时生成版本号和变更摘要。`content.json`、知识库索引和素材目录需要每日备份，恢复演练至少做一次。生产环境禁止把管理员密码写进前端，密码应使用服务器环境变量并强制 HTTPS。

### 4. 完成资产与版权清单

为每张图片、视频、音频、GLB 和纹理补充 `source`、`license`、`author`、`transform` 字段。竞赛开放数据是非商业授权，外部百科图片不能直接作为上线素材；没有授权的内容只能作为内部参考，不进入公开页面。

### 5. 做一次真实部署验收

至少验证：域名 HTTP/HTTPS、备案号、Nginx 转发、服务重启自动恢复、GitHub 更新不覆盖 `content.json`、管理员登录、模型加载失败回退、移动端访问和服务器磁盘空间。验收记录和截图可直接作为提交材料的一部分。

## 三、下一步优先开发（P1）

1. **数据护照页**：用时间线或表格展示“官方数据 → 清洗 → 证据 → 人工审核 → 页面/智能体”的流向。
2. **证据联动**：每个步骤的“为什么这样做”对应一段纪录片时间码；智能体回答只引用已审核条目，资料不足时明确说“不确定”。
3. **一个完整工作台**：为主线项目补齐材料状态、正确动作、失败提示、快速填入、完成品展示和作品来源，保证从地图到成品全程可演示。
4. **成品模型质量**：风筝优先检查彩绘贴图、透明蒙面和细骨架；皮影优先检查透光材质、镂空细节和操纵杆。移动端提供低采样档，避免 10 万粒子同时占满显存。
5. **空状态与可访问性**：没有项目的地区仍显示简介；地图操作提供列表、键盘焦点和触屏等价路径；所有重要图片有真实名称和来源文本。

## 四、可以后做（P2）

- 收藏、浏览路径和体验完成率等匿名事件，用于判断公众对地区、项目和工序的兴趣。
- 基于已审核项目的关联推荐，例如“同一地区的材料”“同一工序的技法”，不要先做开放式推荐。
- 轻量的移动端 3D 预览、静态截图回退和离线素材缓存。
- 多语言或方言讲解，前提是已有可靠文本和音频来源。

## 五、建议的开发顺序

1. 内容与版权冻结：确定 8 个项目的正式名称、地区归属、来源和公开状态。
2. 主线闭环：选择一个项目，把地图、详情、工作台、成品、证据和小蕉问答连通并录制演示路径。
3. 稳定性验收：执行 UI 冒烟、模型加载失败、低性能、移动端、HTTPS 和备份恢复测试。
4. 评审包装：制作数据流向图、系统架构图、3 分钟演示视频、作品说明 PPT/PDF 和公开访问地址。
5. 再扩展内容：只有主线闭环稳定后，才继续增加模型、动画或新的非遗项目。

## 六、上线前验收标准

- 评审可以在 3 分钟内完成“地图定位 → 项目简介 → 工序体验 → 成品 → 来源证据”。
- 每一条核心事实都能回答“来自哪里、如何处理、是否审核”。
- 任何 GLB、纹理或视频加载失败都有可读的平面/图片回退，不阻塞页面。
- 地图页不出现遮挡地图的粒子；成品页粒子颜色来自贴图而不是统一墨色，且下坠消散不会让模型永久缺失。
- 管理员编辑、发布、回滚和备份恢复均有记录；访客不能访问管理接口。
- 电脑、手机和减少动态效果模式都能完成同一条主线体验。
