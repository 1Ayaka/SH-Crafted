# 手势交互重构说明

本版将手势输入统一映射为与鼠标相同的“指向、按下、持续移动、释放”语义。地图、知识星图和工艺模型只负责处理各自的 Three.js 视角，不再分别判断手势状态。

## 操作映射

- 食指移动：移动虚拟指针并触发悬停。
- 捏合后立即松开：点击按下时锁定的目标，允许轻微抖动。
- 捏合保持并移动：拖动当前场景，左右改变水平旋转，上下改变俯仰。
- 张掌按住并移动：直接拖动当前场景，释放后结束拖拽。
- 拖动过程中离开原节点：仍作用于按下时的 Three.js 场景，不会丢失地图旋转。
- 模态框、智能体面板和普通 DOM 控件上的张掌不会穿透旋转后面的场景。

## 验证

```bash
npm.cmd run gesture:test
npm.cmd run graph:test-ui
```

`gesture:test` 会验证点击阈值、拖动增量、释放状态和场景上下文锁定；`graph:test-ui` 会在真实浏览器中模拟地图射线命中、选择、张掌拖动、模型旋转和星图拖动，并检查相机位置确实改变。

控制器提供 `controller.simulate(event)` 作为诊断入口。它只用于自动化测试或开发调试，生产环境仍由摄像头和 MediaPipe 产生同样的事件。
