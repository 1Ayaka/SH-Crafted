# 背景分层与转场系统

本站所有「画在纸上的页面」共用同一条管线：**画作 → 亮度分层（图层 + manifest）→ 页面按 manifest 消费 → 页面之间用穿越转场衔接**。本文档说明整条管线与复用方法，面向后续接入新页面（如工艺详情页）的维护者。

涉及文件：

| 角色 | 文件 |
|---|---|
| 离线分层脚本 | `tools/split_layers.py` |
| 分层背景组件 | `js/layerbg.js` |
| 墨晕交互模块 | `js/inkbloom.js` |
| 跨页转场系统 | `js/transitions.js` |
| 已有页面示例 | `js/views/home.js`（t01）、`js/views/explore.js`（t02）、`js/views/craft.js`（工艺专属背景，见 (g)） |
| 图层产物 | `assets/bg/`（首页）、`assets/bg2/`（地图页）、`assets/bg-crafts/<craftId>/`（工艺页） |
| 三维墨点模型 | `js/particlemodel.js`（见 (h)） |

## (a) 画作 → 图层 + manifest

```bash
python tools/split_layers.py <源图> [--out 输出目录]
# 例：python tools/split_layers.py assets/t01.jpg --out assets/bg   （首页，默认参数即此）
# 例：python tools/split_layers.py assets/t02.jpg --out assets/bg2  （地图页）
```

- 不修改原图；把宽缩到 1280px，按**亮度与色相**拆成 4 层 RGBA WebP（quality 82）。
- 输出 `layer-{wash,mid,dark,gold}.webp` + `manifest.json`，并做**合成校验**（四层叠在砂色底上 vs 原图，平均像素差需远低于 32/255，当前 t01≈9.0、t02≈7.4）。
- 某层没有像素（例如新图无金箔色）会输出空层，属正常边界，JS 端会跳过。

### manifest.json schema

```jsonc
{
  "source": "assets/t01.jpg",        // 源图（相对项目根目录）
  "generated_at": "2026-07-26T…",    // 生成时间（Asia/Shanghai）
  "width": 1280, "height": 853,      // 图层尺寸
  "layers": [                        // 顺序 = 后 → 前（index 0 是最后排的 base 层）
    {
      "file": "layer-wash.webp",     // 文件名（与 manifest 同目录）
      "role": "wash",                // 角色：wash 纸洗 / mid 中间调 / dark 暗部墨团 / gold 金箔
      "parallax": 0.22,              // 鼠标视差系数（0–1，后排小、前排大）
      "drift": 7,                    // 漂移振幅 px（0 = 不漂移）
      "speed": 0.00011               // 漂移角速度（配合正弦，≈ 周期 40–60s）
    }
  ],
  "particle_sources": ["dark", "gold"]  // 墨晕/调色采样来源层（前排有墨有色的层）
}
```

**约定**：`layers[0]`（wash）是 base 层，转场时作为「落点」始终可见；`role` 决定 JS 行为（漂移、采样池），数值全部由脚本写入，**JS 不硬编码任何图片相关数值**。

## (b) 页面如何消费 manifest —— `js/layerbg.js`

```js
import { createLayerBG } from '../layerbg.js';

const bg = await createLayerBG('assets/bg2/manifest.json', {
  scrim: 'top',        // 'left' 左侧文字纱罩（首页）| 'top' 顶部导航纱罩（地图页）| null
  enter: enterFlag,    // 是否播放进场（见 (d)）
  parallax: true,      // 鼠标视差（系数读 manifest）
  drift: true,         // 后排漂移（drift/speed 读 manifest）
  fixed: true,         // true → position:fixed（长页面）；false → absolute（单屏页）
  active: true,        // false 时先挂载但不启动动画，可稍后用 setActive(true) 启用
});
wrap.appendChild(bg.el);   // .bg-stack 元素；z-index 在其内部按层递增
// …页面 cleanup 时：
bg.destroy();
```

返回对象：

| 字段 | 说明 |
|---|---|
| `bg.el` | `.bg-stack` DOM（图层 img + 可选 scrim） |
| `bg.manifest` / `bg.layers` / `bg.bgDir` | manifest 本体、layers 数组、资源目录前缀 |
| `bg.layerEls` | 各层 `<img>`（转场系统直接操作） |
| `bg.fadeEls` | 数组。离场时要一并淡出的覆盖层（如墨晕画布），`push` 进去即可 |
| `bg.zoomThrough()` | 离场动画：前排图层由前到后放大掠过镜头（base 层保留），Promise 在交棒点 resolve |
| `bg.setActive(value)` | 显式启停该背景的漂移/视差循环；工艺背景与工作台背景用它互斥运行 |
| `bg.destroy()` | 停止 rAF 与监听器（DOM 由路由或转场 ghost 回收） |

进场（`enter: true` 且非 reduced-motion）：base 层立即可见，其余层 `opacity 0 + scale 1.09` → 依次（每层延迟 150ms）淡入并落定到 `scale 1.04`，全部落定后才启动漂移/视差循环。

## (c) 墨晕交互 —— `js/inkbloom.js`

鼠标经过处开出墨团，如笔尖染纸。配方对应 AE 三连：**分形杂色（fbm）→ 湍流置换（噪声边缘随时间演化）→ 径向模糊（径向渐变衰减）**，Canvas 2D 自包含实现。模块有两种模式，首页两层画布各挂一个实例：

- **交互层**（默认 `mode: 'interactive'`）：scrim 之上、UI 之下的画布；鼠标拖尾墨团 + 稀疏小环境墨晕。
- **底层环境层**（`mode: 'ambient'`）：插在 **base 层 img 之后**（同 z-index 1，位于 mid/dark/gold 层之下）的画布；只有大而慢的环境墨晕，被上层墨层部分遮盖，读起来像画作本身在呼吸，而不是浮在内容上的特效。

```js
import { createInkBloom } from '../inkbloom.js';

// 交互层（默认参数即可）
const bloom = createInkBloom(canvasEl, bg.manifest, bg.bgDir, {
  trailDist: 30,               // 鼠标拖尾生成间距 px
  trailAlpha: [0.10, 0.17],    // 拖尾墨团透明度区间（淡墨）
  ambientEvery: [1.6, 3.4],    // 交互层环境墨晕间隔秒数区间
  ambientAlpha: [0.05, 0.09],
  maxBlots: 70,                // 同屏墨团上限
});

// 底层环境层（首页用法；全部参数集中在 ambient 里，方便调）
const ambientBloom = createInkBloom(baseCanvasEl, bg.manifest, bg.bgDir, {
  mode: 'ambient',
  sampleMid: true,             // 调色时掺入 mid 层中间调（≈45%），落在纸洗色调里
  ambient: {
    maxAlive: 5,               // 同时存活上限（克制；达到上限暂停生成）
    interval: [3.5, 7],        // 生成间隔（秒）
    maxR: [34, 110],           // 半径区间（大小差异明显）
    alpha: [0.05, 0.11],       // 峰值透明度（淡墨）
    grow: [3, 6],              // 洇开时长（秒，很慢）
    hold: [2, 5],              // 峰值保持（秒）
    fade: [6, 12],             // 淡出时长（秒，很慢）
  },
  avoidRect: () => rectOrNull, // 可选：环境墨晕避开的画布坐标区域（如标题文案块）
});
// 页面 cleanup：bloom.destroy(); ambientBloom.destroy();
```

底层环境层的行为细节：落点 80% 概率取自 dark 层 alpha>60 的**有墨区域**候选点（±30px 抖动，cover-fit 映射），20% 全屏随机；命中 `avoidRect`（含 0.4·maxR 边距）会重抽至多 4 次、仍命中则本轮放弃；首团在挂载后约 1.5s 出现。页面隐藏暂停 rAF；`prefers-reduced-motion` 两种模式都不启用（返回 no-op）。

### 实现要点

- **噪声**：值噪声 + 4 倍频 fbm（`makeNoise`），种子随机。
- **墨团**：64 顶点闭合路径，半径 `R(θ,t) = R·(0.66 + 0.34·(0.5 + 0.5·fbm(cosθ·f + seed, sinθ·f + seed·1.7 + t·evolve)))`；`fScale ∈ [1.5, 2.7]` 控制边缘褶皱频率，`evolve ∈ [0.35, 0.65]` 控制湍流演化速度。
- **填充**：径向渐变（中心 alpha·0.95 → 55% 处 alpha·0.5 → 边缘 0）+ 小半径「墨心」二次叠加；`globalCompositeOperation = 'multiply'`，多层叠加如宣纸积墨。
- **生命周期**：grow（easeOutCubic 扩张 1.1–2.6s，前 22% 快速显影）→ hold → fade（淡出并微扩 14%）。
- **调色**：从 `manifest.particle_sources` 指定层离线采样像素色（dark 层 → 松绿墨池，gold 层 → 金箔池），拖尾墨团 8% 概率用金；`sampleMid: true` 时另采 mid 层中间调池（ambient 模式 ≈45% 取用）。
- **环境墨晕**：交互层每 1.6–3.4s 一小团（更大更淡，页面静止时也呼吸）；ambient 模式的底层墨晕见上文参数表，大而慢、克制长存。
- **上限与暂停**：同屏上限 `maxBlots`（默认 70，超出挤掉最旧；ambient 模式用 `maxAlive` 封顶，到顶暂停生成）；标签页隐藏暂停 rAF；`prefers-reduced-motion` 时模块直接不启用（返回 no-op），仅静态背景。
- **调参**：要更浓 → 提高 `trailAlpha` / `ambient.alpha`；要更密 → 减小 `trailDist` / `ambient.interval`；要更大 → 提高 `ambient.maxR` 上限；要更慢消散 → 提高 `ambient.fade`。

## (d) 跨页转场 —— `js/transitions.js`

概念：每个页面声明自己的分层背景（manifest）+ 内容进场动画；`transitionTo(route)` 把「当前页图层穿越」与「下一页落点接应」缝成连续运动，无硬切。

### API

```js
import { registerPage, unregisterPage, transitionTo, consumeEnter, isTransitioning } from '../transitions.js';

registerPage('home', {
  root: wrap,        // 页面根元素（reduced-motion 时整页交叉淡出用）
  bg,                // createLayerBG 的返回值（无分层背景的页面可省略）
  fadeUI() { /* 把页面 UI 加 .ui-fade（240ms 淡出） */ },
});
// 视图函数开头：
const entering = consumeEnter();   // true = 本次挂载来自转场，应播进场（只生效一次）
// cleanup：
unregisterPage('home');
```

### `transitionTo('#/explore')` 逐步行为

1. 守卫：转场进行中直接返回 `false`；调用方应配合 `isTransitioning()` 忽略输入。
2. `fadeUI()`：当前页 UI 淡出（240ms）。
3. `bg.zoomThrough()`：前排图层**由前到后**放大掠过镜头（`transform 560ms + opacity 380ms`，每层延迟 75ms，仅 transform/opacity）；最大缩放约 2.34，base 层保留，减少全屏纹理放大造成的合成卡顿。
4. 旧背景整体提升为 `body` 下的 fixed **ghost**（`.bg-ghost`）→ `navigate(hash)` → 路由用独立 `.route-mount` 挂载新页；新页 base 层立即可见，ghost 在约 520ms 内淡出回收。路由代次号会清理快速切页产生的过期异步视图，避免旧页面反向覆盖新页面。
5. ghost 380ms 淡出回收 → base → base 交叉淡融，完成。
6. 新页内容进场由页面自己实现：地图页 = 3D 场景弧线俯冲（`map3d.playEnter()`，约 3.2s 落到用户面前）；平面兜底 = `.enter-pop` 轻微放大。转场状态名沿用产品大纲预留：`home_exit`（首页离场标记类）/ `map_enter`（地图页进场标记类）。
7. `prefers-reduced-motion`：跳过穿越，整页 `.page-xfade` 240ms 交叉淡入淡出。

### 地图页玉石与边缘粒子瀑布

- 正式模型为 `assets/models/上海map_v2.glb`：11 个历史行政区节点均带真实厚度，另含“以外的陆地”节点。外部陆地固定使用灰色半透明材质，不参与行政区命中和数据粒子。
- 行政区主体使用 `MeshPhysicalMaterial` 的透射、体积厚度、衰减色、折射率、清漆、环境反射和正面单次渲染模拟玉石；自定义着色器按模型局部 Y 坐标把顶部保持为实体显示，向底部平滑过渡到 8% 透明度，并把底色收敛到粒子色 `#3C493D`。
- `assets/t地图贴图.png` 是玉石像素来源：运行时从整张画的不同区域按固定随机种子裁片，组成低对比纹理图集，再叠加淡玉色与细矿脉；各行政区对图集采用不同的缩放和偏移，避免机械重复，同时限制深墨与亮纸区域对玉色统一性的影响。
- 地图页不再渲染独立水面。透明画布直接露出分层背景，避免水面高光、法线和地图顶面争夺层级。
- 地图页不再渲染边缘粒子瀑布，保持玉石模型与分层水墨背景之间的留白；地图上的数据通过区块高亮、项目图片按钮和右侧简介表达。成品粒子仅在详情页使用，并承担模型揭晓、轻微下坠与消散效果。
- 行政区边缘线默认使用极淡玉灰色，只在悬停和聚焦时适度增强；不再以黑色线条切割每一个区块。
- 区块悬停时上浮高度提高，并暂停该区粒子补充；当前仍在运动的粒子会获得一次向外、向下的加速度，形成从玉石边缘被抖落的过渡。移开鼠标后，粒子随区块回落逐步恢复生成。
- `prefers-reduced-motion` 开启时，区块位置瞬时变化，粒子保持静止。

### 首页荷花荷叶精灵

- `js/homeparticles.js` 从首页背景第一层（`wash`）当前 `cover` 裁切的真实显示区域取样明暗分布，使用 `assets/t荷叶.png` 与 `assets/t荷花.png` 布置水墨图片精灵；两张绿幕素材在运行时自动完成柔边色键，无需另存透明图。
- 精灵只聚集在左下和右上两片椭圆区域，左下约占 57%、右上约占 43%。普通窗口固定显示 2 朵荷花，大屏显示 3 朵，其余精灵全部使用荷叶；桌面端最多 58 个，通过局部重叠形成密度，同时让中部标题、统计和主要操作区域保持留白。
- 精灵保持缓慢呼吸，鼠标划过时向两侧荡开并缓慢回位；点击时从落点向外扩散，随后由既有首页转场进入地图。素材入口统一由 `homeView` 的 `spriteSources` 声明，补充花型图片不需要修改运动逻辑。
- 图片精灵以弹簧约束围绕各自原点缓慢呼吸。鼠标经过时产生局部排斥，移开后逐渐回位；点击空白处时从点击点快速扩散并淡出，约 295ms 后交给既有 `transitionTo('#/explore')` 完成跨页转场。
- 桌面端根据可视面积动态控制密度；移动端降低数量并限制为 30fps。标签页隐藏、页面销毁和 `prefers-reduced-motion` 均有独立的停止或降级路径。

### 接入新页面（如工艺详情页）

1. 准备画作并分层：`python tools/split_layers.py assets/t0X.jpg --out assets/bgX`。
2. 视图函数开头 `const entering = consumeEnter();`，然后 `createLayerBG('assets/bgX/manifest.json', { enter: entering, … })`。
3. `registerPage('craft', { root, bg, fadeUI })`；cleanup 里 `bg.destroy()` + `unregisterPage('craft')`。
4. 给内容写进场动画（`entering === true` 时播放），离场无需处理 —— `transitionTo` 会驱动 `bg.zoomThrough()`。
5. 从别的页面跳转时调用 `transitionTo('#/craft/…')` 而不是 `navigate()`，即自动获得穿越效果。

```bash
# 1) 新图放进 assets/
# 2) 一条命令重建该页全部派生资产（以地图页为例）
python tools/split_layers.py assets/新图.jpg --out assets/bg2
# 3) 刷新页面 —— 图层、视差、漂移、墨晕调色全部走 manifest，JS 零改动
```

## (f) 无障碍与性能规则

- **reduced-motion**：分层背景静止（无漂移/视差/进出场）；墨晕模块完全不启用；首页荷花荷叶精灵降密并保持静态；转场退化为 240ms 交叉淡入淡出；三维地图无俯冲与弧线 tween（瞬时到位）、区块上浮瞬时。
- **标签页隐藏**：layerbg 漂移循环、inkbloom rAF、map3d 主循环全部暂停。
- **背景帧率**：layerbg 环境漂移限制为 30fps，只更新 manifest 中实际启用漂移或视差的图层；工艺页与工作台的两套背景互斥运行。
- **封顶**：墨晕同屏 ≤ 70；首页图片精灵按可视面积自适应，桌面不超过 58 个、移动端不超过 42 个；其余粒子采样池抽稀（ink ≤900 / gold ≤240 / 环境点 ≤600）；图层宽 ≤1280px。
- **动画只用 transform/opacity**；WebP quality 82；DPR 上限 2。
- **图例诚实**：地图页不使用装饰粒子模拟数据；区块高亮、项目数量和详情页成品粒子均应与真实数据或明确的展示状态对应。

## (g) 工艺专属背景 —— `assets/bg-crafts/<craftId>/`

工艺详情页（`js/views/craft.js`）不再共用首页/地图页画作，而是**每个工艺一张专属背景画**，目录按路由 id 约定：

```
assets/bg-crafts/
  src/                       # 源图（不入图层产物，仅留档与重建用）
    SHIH_0001.jpg            # 命名约定：<craftId>.<ext>
    SHIH_0002.png …
  SHIH_0001/  manifest.json + layer-{wash,mid,dark,gold}.webp
  SHIH_0002/  …（八个工艺各一套，合成校验差 5.5–15.4 / 255）
```

换图 / 新工艺接入：

```bash
# 1) 新图按 <craftId>.<ext> 命名放入 assets/bg-crafts/src/
# 2) 重建该工艺的全部图层
python tools/split_layers.py assets/bg-crafts/src/SHIH_0001.jpg --out assets/bg-crafts/SHIH_0001
# 3) 刷新页面 —— craft.js 按 `assets/bg-crafts/${id}/manifest.json` 取图，JS 零改动
```

craft 页的消费方式与 (b)(c)(d) 完全同管线：`createLayerBG(manifest, { scrim: 'left', enter: consumeEnter(), parallax: true, fixed: true })` + 底层环境墨晕（ambient 参数与首页同族，略更克制：maxAlive 4、alpha 0.04–0.09）+ `registerPage('craft', …)`。home → explore → craft 全程均为穿越转场（explore.js 内所有工艺跳转一律走 `transitionTo`，不再用 `navigate`）；craft 页内「← 返回地图」与 Esc 回退也走 `transitionTo('#/explore')`。

### 工作台进行态背景 —— `assets/bg-workbench/`

## (h) 三维墨点模型 —— `js/particlemodel.js`

工作台把 GLB 模型表面采样为 2.4–6 万颗点，用一张**黑→灰连续遮罩**沿模型局部 X 轴决定每颗点的行为强度：越黑越稳定，越灰越活跃。带 `baseColorTexture` 的材质会先进入 512px 像素缓存，粒子按真实 UV 取色；风筝保留彩绘，皮影保留透雕明暗。遮罩值 v（0–1 亮度）连续作用于漂移、透明度和下坠，无阈值分段：

- 漂移速度：+x 向流速 ∝ v（`flowSpeed × v`，带个体相位噪声），到达 `maxTravel = 0.08 + v×0.32` 后渐隐、回家淡入重生（`RESPAWN_FADE = 0.7s`，粒子总数守恒）；
- 透明度下限：`aMul = fade × travelFade × (1 − FADE_MIN×v)`，`FADE_MIN = 0.55`，灰端最低保留 45% 基础透明度；
- 成品下坠：完成态按 `dropRate = 0.075` 让不同密度的点向下漂移，达到阈值后渐隐并从原位补回，避免模型突然断裂；
- 微颤幅度：`0.006 × (1 − v×0.55)`，稳定区不累积位移。

```js
const { createParticleModel, preloadModel, preloadPattern } = await import('../particlemodel.js');   // 懒加载 three/GLTFLoader
const h = await createParticleModel(containerEl, url, { tint, patternUrl, patternRepeat });
// h = { el, setActive(bool), scatter(), playEnter(), playDyeSweep(dur?), dispose() }
```

### 关键参数（模块顶部常量）

| 常量 | 值 | 含义 |
|---|---|---|
| `MIN_PTS` / `MAX_PTS` / `DENSITY` | 24000 / 60000 / 12000 | 点数 = clamp(模型表面积 × 12000, 2.4万, 6万)，按各 mesh 面积分配 |
| `TARGET_DIM` | 2.2 | 模型归一化到最长边 2.2 个场景单位；相机 `camHome (0, 0.35, 3.72)` + fov 40 完整入画 |
| `FADE_MIN` / `RESPAWN_FADE` | 0.55 / 0.7s | 灰端透明度下限系数 / 漂移重生淡入时长 |
| `SCATTER_BURST / HOLD / BACK` | 0.25 / 0.35 / 1.7s | 散墨三段包络：外爆（easeOut）→ 停顿 → 合并回家（easeInOut），漂移在散墨期间被压制 85% 保证干净合并 |
| `ENTER_DUR` | 1.7s | 完成态进场：相机自 (1.8, 3.4, 9.6) 弧线俯冲落位（easeInOutQuart + 侧摆），点云 uFade 淡入 |

遮罩文件 `assets/mask-gradient-ltr.png`（左黑右灰连续渐变），加载后降采样到 64×8 逐点查表，全模块共享一次加载；加载失败退化为按 X 线性渐变。

### 表面采样（自写，替代 MeshSurfaceSampler）

面积加权 + 重心插值，同时取**位置与 UV**：UV 供平面模型的纹样取色与染色扫过。GLB/纹样均有模块级缓存（`preloadModel/preloadPattern` 提前 warm，完成态揭晓瞬时）。平面模型自动转正：最薄轴为 Y 时 `baseRotX = −π/2` 立起面向镜头（如撕纸原料 XZ 水平面；药斑布 XY 竖直面本就朝向镜头，不转）。

### 配色与纹样

- 默认墨绿/松墨/鼠尾草 + ≈8% 金箔点；`tint` 覆盖为单色原料（未染布 0xC4AE8C、白纸 0xD8CCAF——均略深于砂底保证可读）。
- `patternUrl`（药斑布成品）：纹样图降采样 256×256，按 UV 取色，靛蓝判定 `b > r+14 && b >= g && r+g+b < 600`；染区取 INDIGO 三色池，防染白区取 RESIST 米白且点更小更淡（sizeMul 0.62 / alphaMul 0.5）。`patternRepeat [1,2]` 平铺。
- `playDyeSweep(dur = 2.6)`：染色前沿沿 UV-u 推进（带宽约 0.09 的噪声软边），粒子色由原料色插值到纹样色——同一布面完成「染靛」揭晓。

### 主循环稳健性

- 时钟统一取 `performance.now()`，dt 钳制 `[0, 0.05]`：rAF 回调时间戳在 headless 虚拟时间下会冻结或与时钟不同源，负 dt 会把 enterAge 等计时器打负、卡死 uFade。
- 调度 = rAF 优先 + `setTimeout(120ms)` 心跳兜底（先到先跑、互相取消）：headless 截图模式下 rAF 会饥饿，心跳保证动画推进；真实浏览器中心跳永远被 rAF 抢先取消，零开销。
- **渲染缓冲与基础值必须隔离**：`aAlpha` 属性用 `alphas.slice()` 挂载——tick 每帧「读基础 alpha × aMul 写渲染数组」，若同一块缓冲则透明度逐帧连乘、高 v 区几十帧内衰减到不可见。

### 交互与生命周期

- **拖拽旋转**：Y 轴自由 + X 轴限幅（±0.5 rad），带阻尼。
- **无拖拽点击**：`scatter()` —— 三段包络外爆后自动合并回家。
- **reduced-motion**：不散墨、不进场动画；染色瞬时完成；静态渲染。
- **暂停**：`IntersectionObserver` 离屏 + `visibilitychange` 标签页隐藏时停循环（也可手动 `setActive(false)`）。
- **dispose()**：释放 geometry / material / renderer / 监听器 / 心跳定时器；路由 cleanup 必须调用（craft.js 用 `pmHandles` 数组统一登记，`clearWorkbench()` 与页面 cleanup 各 dispose 一次）。
